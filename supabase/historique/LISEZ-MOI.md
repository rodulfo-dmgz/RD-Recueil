# Historique des migrations (archive, ne plus executer)

Ces fichiers racontent l'évolution de la base de production d'origine (projet Supabase rd-flow), avant le passage au préfixe `crm_`. Ils référencent les anciens noms (`clients`, `rpc_changer_statut`…). **Une nouvelle installation n'en a pas besoin** : elle utilise uniquement `supabase/migrations/20261007000000_crm_install.sql` puis `supabase/seed/seed_v1.sql`.
